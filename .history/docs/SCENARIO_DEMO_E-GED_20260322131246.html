Prérequis pour la démo
  • Durée estimée : 15 à 20 minutes
  • Fichiers : 1 PDF de test (ex. cahier des charges, rapport technique)
  • Navigateur : Firefox ou Chrome, fenêtre en plein écran

Comptes de test (adaptés DDSAIT)

CompteMot de passeUsage
dir.ddsait@acsi.cg password Directeur DDSAIT – vue structure, validation
utilisateur@acsi.cg password Ingénieur / utilisateur – dépôt, envoi validation
dg@acsi.cg password DG – vue globale (optionnel)
admin@acsi.cg password Admin – paramétrage (optionnel)

Pour une démo 100% DDSAIT, créer un compte ingénieur dans la structure DDEV (ex. ingenieur.ddev@acsi.cg) si nécessaire.

SÉQUENCE 1 – Connexion et tableau de bord 2 min

Étapes

  1. Aller sur la page de connexion.
  2. Se connecter avec utilisateur@acsi.cg / password.
  3. Montrer le tableau de bord utilisateur : nombre de documents, derniers documents, dossiers récents / favoris.
« Chaque utilisateur a une vue personnalisée selon son rôle. Ici, l'ingénieur voit ses documents et dossiers. Plus tard, on verra la vue du Directeur DDSAIT. »
SÉQUENCE 2 – Dossiers et arborescence 2 min

Étapes

  1. Cliquer sur Dossiers dans le menu.
  2. Parcourir l'arborescence : Projets → Projet A → Cahier des charges ou Ingénierie SI → Documentation (dossiers liés à la DDSAIT).
  3. Ouvrir un dossier.
  4. Marquer un dossier en favori pour un accès rapide.
« Le plan de classement reflète l'organisation. Les dossiers Projets et Ingénierie SI sont rattachés à notre direction. Le propriétaire est le responsable de la structure, donc un acteur métier. »
SÉQUENCE 3 – Dépôt d'un document 3 min ⭐ PHARE

Étapes

  1. Cliquer sur Documents → Déposer un document.
  2. Glisser-déposer un fichier PDF dans la zone (ou clic pour sélectionner).
  3. Vérifier que le type de document est suggéré (ex. PDF).
  4. Remplir ou modifier les métadonnées : titre, référence (ex. CDC-2025-001), mots-clés.
  5. Choisir le dossier Projets → Projet A → Cahier des charges (ou Documentation).
  6. Cliquer sur Déposer le document.
  7. Montrer le message de succès.
« L'extraction automatique des métadonnées PDF limite la saisie manuelle. Le dépôt est simple : glisser-déposer, compléter si besoin, choisir le dossier. Le responsable du dossier reçoit une notification par email. »
SÉQUENCE 4 – Recherche 1 min 30

Étapes

  1. Aller dans Recherche.
  2. Saisir un mot du titre ou de la référence (ex. « CDC » ou « 2025 »).
  3. Montrer les résultats avec les filtres (type, statut, dossier).
« La recherche permet de retrouver rapidement un document par titre, référence, mots-clés ou description. »
SÉQUENCE 5 – Envoi en validation 3 min ⭐ PHARE

Étapes

  1. Aller dans Documents.
  2. Repérer le document déposé (statut Brouillon).
  3. Cliquer sur Modifier.
  4. Cliquer sur Envoyer en validation.
  5. Expliquer : « Le document part dans la chaîne hiérarchique DDSAIT : Ingénieur → Directeur DDSAIT → DG (selon le workflow configuré). »
  6. Confirmer l'envoi.
  7. Vérifier que le statut passe à En attente.
« Le workflow est configuré par type de document. On peut utiliser une validation directe ou une chaîne hiérarchique basée sur notre structure. Le validateur reçoit une notification. »
SÉQUENCE 6 – Validation (côté validateur) 2 min 30 ⭐ PHARE

Étapes

  1. Se déconnecter (ou ouvrir une fenêtre privée).
  2. Se connecter avec dir.ddsait@acsi.cg / password (Directeur DDSAIT).
  3. Aller dans Notifications : montrer « Document en attente de validation ».
  4. Cliquer sur la notification pour accéder au document.
  5. Choisir Approuver ou Rejeter (avec motif si rejet).
« En tant que Directeur, vous voyez les documents qui vous attendent. L'approbation fait avancer le workflow. Le rejet avec motif permet à l'ingénieur de corriger et renvoyer. »
SÉQUENCE 7 – Vue Directeur DDSAIT 2 min ⭐ PHARE

Étapes

  1. Rester connecté avec dir.ddsait@acsi.cg.
  2. Montrer le tableau de bord par structure (DDSAIT / DDEV) :
    • Nombre de documents, dossiers, utilisateurs de la direction
    • Documents récents
    • Documents en attente de validation
« En tant que Directeur de la DDSAIT, vous avez une vue consolidée sur l'activité de notre direction : dépôts récents, documents en attente de votre validation. »
SÉQUENCE 8 – Partage d'un dossier 1 min 30

Étapes

  1. Aller dans Dossiers.
  2. Ouvrir un dossier dont on est propriétaire (ou utiliser le compte directeur).
  3. Cliquer sur Partager.
  4. Ajouter un utilisateur avec des droits (lecture, écriture).
« Le partage permet d'ouvrir l'accès à un dossier à d'autres utilisateurs, avec des droits précis et une date d'expiration optionnelle. »
SÉQUENCE 9 – Administration (aperçu) 2 min

Étapes

  1. Se connecter avec admin@acsi.cg.
  2. Aller dans Paramètres.
  3. Parcourir rapidement : Structures, Rôles, Plan de classement, Workflow, Journal d'audit.
« L'admin configure l'organisation. Le journal d'audit trace les actions sensibles. »
SÉQUENCE 10 – Corbeille 30 s

Étapes

  1. Supprimer un document test.
  2. Aller dans Corbeille.
  3. Restaurer le document.
« La corbeille permet de récupérer un document supprimé par erreur avant suppression définitive. »

Conseils pour une démo réussie
  1. Préparer les données : lancer php artisan db:seed si besoin.
  2. Préparer un PDF : cahier des charges ou rapport technique avec métadonnées.
  3. Tester le parcours : répéter le scénario une fois avant la présentation.
  4. Adapter au temps : si limité, garder les séquences 1, 3, 5, 6 et 7.
  5. Anticiper les questions : sécurité, sauvegardes, capacité, évolutions.
